# PHP

phpのプロジェクトをまとめたディレクトリ

## シングルクォートとダブルクォートの違い

1. 変数展開

ダブルクォート: 変数を展開する
$name = "太郎";
echo "こんにちは、{$name}さん";  // こんにちは、太郎さん
echo "こんにちは、$name さん";   // こんにちは、太郎さん

シングルクォート: 変数を展開しない（リテラルとして扱う）
$name = "太郎";
echo 'こんにちは、{$name}さん';  // こんにちは、{$name}さん
echo 'こんにちは、$name さん';   // こんにちは、$name さん

2. エスケープシーケンス

ダブルクォート: エスケープシーケンスを解釈する
echo "1行目\n2行目";     // 改行が入る
echo "タブ\t区切り";      // タブが入る

シングルクォート: \' と \\ のみ解釈
echo '1行目\n2行目';     // 1行目\n2行目（\nがそのまま表示）
echo 'It\'s OK';         // It's OK（\'のみ有効）
echo 'C:\\path';         // C:\path（\\のみ有効）

3. パフォーマンス

シングルクォート: わずかに高速
- 変数展開の処理がないため、理論上は速い
- 実際の差は微々たるもの

ダブルクォート: わずかに低速
- 変数展開の解析処理が入る
